# GT63 Design System

Version: 1.0

## Purpose

This document defines the timeless visual language of GT63. It does not describe code, markup, styling syntax, frameworks or rendering technology.

The GT63 Design System translates the Brand Layer into visual behavior. Brand defines why GT63 exists. Design defines how GT63 should feel on every client-facing surface.

## Visual Hierarchy

GT63 hierarchy begins with emotion, then orientation, then decision.

The preferred order is:

1. Destination or journey identity.
2. Selected residence.
3. Journey dates and traveler context.
4. Photography-led atmosphere.
5. Essential journey facts.
6. Investment.
7. Next step.

Avoid making every element equally loud. Luxury depends on prioritization.

## Grid Philosophy

GT63 grids should feel editorial, not mechanical.

Use structure to guide the eye, but avoid visible system rigidity. The traveler should sense order without seeing a spreadsheet.

Good GT63 grids:

- create calm alignment;
- allow large image moments;
- support asymmetry when it feels editorial;
- preserve comfortable reading widths;
- avoid tiny equal boxes.

Bad GT63 grids:

- treat every fact as a card;
- create dashboard density;
- force content into equal modules;
- reduce imagery to thumbnails.

## Typography Hierarchy

Typography is the voice of trust.

GT63 type should have clear levels:

### Journey Title

Used for destination and major emotional moments. Large, elegant and spacious.

### Residence Title

Used for selected residence identity. Clear, premium and easy to read even when long.

### Section Title

Used for page-level orientation. Calm and direct.

### Editorial Body

Used for descriptions and journey story. Comfortable line length and generous rhythm.

### Metadata

Used for dates, travelers, room, meal, route and status. Small but never tiny.

### Investment

Used for total investment and important price context. Prominent but controlled.

## White Space Philosophy

Whitespace is not empty space. It is the signal of care.

GT63 should use whitespace to:

- create luxury perception;
- separate journey moments;
- give photography authority;
- make decisions easier;
- reduce cognitive load.

Never fill a page simply because space exists.

## Color Philosophy

GT63 color should be restrained, warm and premium.

Color should support:

- calm confidence;
- editorial quality;
- readability;
- photographic dominance;
- subtle brand memory.

Avoid:

- loud promotional colors;
- neon accents;
- excessive gradients;
- alert-like price colors;
- palettes that make the journey feel like software.

Color should never compete with photography.

## Photography Philosophy

Photography is the emotional engine of GT63.

Use imagery to create:

- desire;
- place;
- atmosphere;
- trust in the selected residence;
- confidence that the journey is real.

Photography rules:

- one dominant image per major page;
- selected residence imagery should be specific when available;
- destination imagery should support the story, not replace selected residence truth;
- missing images should degrade gracefully;
- never invent imagery as evidence.

## Iconography

GT63 iconography should be rare, quiet and functional.

Icons may support:

- movement;
- time;
- contact;
- location;
- included services;
- optional status.

Icons must not become decoration. If an icon does not clarify meaning, remove it.

Avoid playful, cartoon, gaming or overly technical icon styles.

## Luxury Principles

GT63 luxury is expressed through:

- restraint;
- proportion;
- space;
- precision;
- image quality;
- calm contrast;
- quiet confidence;
- absence of urgency.

Luxury is not created by more ornaments. It is created by removing what weakens the journey.

## Motion Principles

Motion, when used in digital contexts, must be quiet and purposeful.

Motion may:

- guide attention;
- clarify transitions;
- make selection feel smooth;
- reinforce hierarchy.

Motion must not:

- distract from content;
- feel playful when the context is serious;
- slow decision-making;
- create spectacle for its own sake.

Printed and static surfaces should imply motion through sequence, rhythm and page transitions.

## Editorial Principles

GT63 should feel closer to a premium travel magazine than to a software interface.

Editorial design means:

- strong opening image;
- meaningful page sequence;
- clear story arc;
- controlled type hierarchy;
- intentional cropping;
- enough room for the reader;
- captions and facts used with restraint.

Every page should have one editorial idea.

## Decision Clarity

Design must make the selected journey easier to choose.

The traveler should always understand:

- what is selected;
- what is optional;
- what is for confirmation;
- what the investment is;
- who to speak with next.

Beauty without decision clarity is not GT63.

## Timelessness

The GT63 Design System should outlive current visual trends.

Avoid trend dependency:

- no novelty aesthetics;
- no generic AI gloss;
- no seasonal visual gimmicks;
- no style that will look dated quickly.

GT63 should feel modern, but not fashionable.

## Design North Star

Every visual decision must support this outcome:

The traveler feels desire, understands the journey and trusts the next step.
