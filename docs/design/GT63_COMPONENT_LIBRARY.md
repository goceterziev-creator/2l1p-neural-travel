# GT63 Component Library

Version: 1.0

## Purpose

This document defines reusable GT63 presentation components in conceptual terms. It does not define markup, styling syntax, code, frameworks or implementation details.

Components are not decorative blocks. Each component exists to support emotion, clarity or decision-making.

## Hero

### Purpose

Create the primary emotional entry point.

### Emotion

Desire and anticipation.

### Content

Destination, selected residence, journey context, dominant photography and elegant investment signal.

### Hierarchy

Image first, destination second, selected residence third, supporting facts fourth.

### Spacing

Generous. The Hero must never feel crowded.

### Usage Rules

Use once at the beginning of a Journey Book or major presentation.

### Forbidden Usage

- Multiple competing hero images.
- Price as the first emotional signal.
- Dense factual grids.
- Operational labels.

## Destination Header

### Purpose

Orient the traveler around place.

### Emotion

Arrival into the idea of the journey.

### Content

Destination name, short destination story, travel dates and selected context.

### Hierarchy

Destination name dominates. Everything else supports.

### Spacing

Enough room for the destination to feel important.

### Usage Rules

Use at the beginning of a section or page where location context matters.

### Forbidden Usage

- Generic destination slogans.
- Overloaded metadata.
- Repeating the same destination label without purpose.

## Story Block

### Purpose

Turn approved facts into a readable narrative.

### Emotion

Human care and clarity.

### Content

Short editorial text based only on available truth.

### Hierarchy

One title, one body text area, optional supporting fact.

### Spacing

Comfortable line length and generous paragraph rhythm.

### Usage Rules

Use when facts need meaning, not when a list is enough.

### Forbidden Usage

- Generic AI filler.
- Unsupported claims.
- Long walls of text.

## Residence Card

### Purpose

Present a residence option clearly.

### Emotion

Confidence and comparison clarity.

### Content

Residence name, image when available, category, room, meal, location, investment and selected status.

### Hierarchy

Selected status must be clear. Name and image lead. Details support.

### Spacing

Compact but not cramped.

### Usage Rules

Use for comparison or alternative context.

### Forbidden Usage

- Full brochure details for every alternative.
- Making all residences feel equally selected.
- Overusing badges.

## Selected Residence Feature

### Purpose

Make the selected residence feel like the anchor of the journey.

### Emotion

Desire and reassurance.

### Content

Residence name, large photography, description, room, meal, location, factual highlights and investment context.

### Hierarchy

Image and name first. Details follow in a curated sequence.

### Spacing

Spacious and editorial.

### Usage Rules

Use only for the canonical selected residence.

### Forbidden Usage

- Showing multiple residence features in selected mode.
- Inventing advantages.
- Reducing the selected residence to a small card.

## Timeline

### Purpose

Show the flow of the journey.

### Emotion

Ease and anticipation.

### Content

Departure, arrival, stay period, supplied events, return and other confirmed journey moments.

### Hierarchy

Date or moment marker first, event title second, details third.

### Spacing

Each moment should breathe.

### Usage Rules

Use only when timeline data exists or when confirmed journey movement needs clarity.

### Forbidden Usage

- Invented activities.
- Forced empty days.
- Dense operational itinerary dumps.

## Investment Card

### Purpose

Show total investment clearly without making the journey feel transactional.

### Emotion

Confidence.

### Content

Total investment, currency, selected context, validity or confirmation note when available.

### Hierarchy

Amount is clear. Context prevents misunderstanding.

### Spacing

Calm and isolated from visual noise.

### Usage Rules

Use where decision context requires price clarity.

### Forbidden Usage

- Discount styling.
- Alarm colors.
- Price repeated on every page without purpose.

## Gallery

### Purpose

Support desire through additional visual context.

### Emotion

Exploration.

### Content

Approved images connected to the destination, selected residence or optional experience.

### Hierarchy

One image should lead. Others must be secondary.

### Spacing

Enough separation to avoid catalogue feeling.

### Usage Rules

Use only when images are meaningful and stable.

### Forbidden Usage

- Tiny unprioritized thumbnails.
- Images from the wrong residence.
- Generic filler imagery.

## Quote

### Purpose

Create a quiet editorial pause.

### Emotion

Reflection.

### Content

Only verified human, brand or advisor text when available.

### Hierarchy

Quote first, attribution second.

### Spacing

Generous.

### Usage Rules

Use rarely.

### Forbidden Usage

- Invented testimonials.
- Generic inspirational quotes.
- Decorative quote marks without real content.

## Section Divider

### Purpose

Create rhythm between major journey moments.

### Emotion

Calm transition.

### Content

Short label, page title or quiet visual pause.

### Hierarchy

Minimal. A divider should not compete with content.

### Spacing

Use space more than ornament.

### Usage Rules

Use when a journey shift needs emphasis.

### Forbidden Usage

- Heavy borders.
- Decorative clutter.
- Repeating dividers too often.

## Service List

### Purpose

Clarify what is included, optional or for confirmation.

### Emotion

Reassurance.

### Content

Flights, residence, meal, baggage, transfers, advisor support, conditions and supplied inclusions.

### Hierarchy

Confirmed items first. Optional and unconfirmed items clearly marked.

### Spacing

Grouped by meaning, not by equal boxes.

### Usage Rules

Use when service clarity supports trust.

### Forbidden Usage

- Invented inclusions.
- Hiding uncertainty.
- Turning services into a dense grid of widgets.

## Final Message

### Purpose

Close the Journey Book with confidence and a clear next step.

### Emotion

Readiness.

### Content

Final statement, selected journey, investment, validity or condition note, advisor contact and next step.

### Hierarchy

Message first, journey and investment second, contact third.

### Spacing

Very generous. The ending should feel composed.

### Usage Rules

Use once at the end.

### Forbidden Usage

- Administrative footer language.
- Multiple competing actions.
- Unsupported booking guarantees.
- Technical document references.

## Component Standard

Every GT63 component must answer:

1. What emotion does it create?
2. What decision does it support?
3. What truth does it clarify?
4. What noise does it remove?

If a component cannot answer these questions, it should not exist.
