# GT63 Design Rules

Version: 1.0

## Purpose

These are strict visual and experience rules for GT63. They apply to client-facing presentations, digital journeys, printed journeys, pages, interfaces and future presentation surfaces.

This is Version 1.0 of the GT63 Brand Layer. Future versions may add rules, refine examples and expand guidance, but should not replace the timeless principles of desire, clarity, trust and restraint.

Use this document together with [GT63_EXPERIENCE_BIBLE_EN.md](./GT63_EXPERIENCE_BIBLE_EN.md) and [GT63_WORDS.md](./GT63_WORDS.md).

## Rule 1: Emotion Before Information

### Purpose

Create desire before asking the traveler to evaluate details.

### Reason

Premium travel decisions begin with feeling. Information matters, but it becomes persuasive only after the traveler wants the journey.

### Examples

- Start with destination, selected residence and photography.
- Move price and conditions into an elegant supporting role.

### Bad Example

Opening a client presentation with a price table, baggage details and hotel comparison grid.

### Good Example

Opening with a cinematic destination page, selected residence identity, travel dates and a calm investment signal.

## Rule 2: One Hero Image per Page

### Purpose

Give each page one clear visual leader.

### Reason

Multiple competing images reduce luxury perception and create catalogue energy.

### Examples

- Cover: one dominant hero.
- Hotel page: one primary selected residence image.
- Optional experiences: one image per experience only when it adds clarity.

### Bad Example

Six equal thumbnails on a page with no hierarchy.

### Good Example

One large image supported by one or two quiet secondary details only when space allows.

## Rule 3: Never Start with Price

### Purpose

Prevent the journey from feeling like a commodity.

### Reason

In premium travel, price supports the decision. It does not create the dream.

### Examples

- Present destination and selected residence first.
- Show total investment clearly after emotional orientation.

### Bad Example

"5,431.93 EUR" as the first or largest element on the cover.

### Good Example

Destination first, selected residence second, dates and travelers third, investment placed elegantly as a supporting anchor.

## Rule 4: Whitespace Is Part of the Design

### Purpose

Use space to communicate confidence and premium quality.

### Reason

Luxury does not fill every available area. Crowding signals insecurity and automation.

### Examples

- Leave room around titles.
- Avoid dense grids.
- Let images breathe.

### Bad Example

Every page packed with cards, borders, badges and small labels.

### Good Example

Fewer elements, stronger spacing and a clear reading path.

## Rule 5: Typography Creates Trust

### Purpose

Make the document feel editorial, precise and expensive.

### Reason

Type hierarchy is one of the fastest ways a traveler judges quality.

### Examples

- Large type for destination and major page moments.
- Medium type for selected residence and section titles.
- Comfortable body text with readable line length.

### Bad Example

Tiny UI labels, compressed rows and dashboard-style typography.

### Good Example

Calm serif headings, precise supporting text and restrained sans-serif metadata.

## Rule 6: Photography Creates Desire

### Purpose

Use imagery as the emotional engine of the presentation.

### Reason

The traveler needs to see themselves in the journey before they can commit to it.

### Examples

- Use selected residence imagery when the selected residence is the decision.
- Use clean placeholders only when imagery is missing or unsafe.

### Bad Example

Hiding all imagery in a client presentation and calling the result premium.

### Good Example

Rendering safe approved images and degrading broken images to elegant placeholders.

## Rule 7: Every Page Has One Emotional Goal

### Purpose

Prevent page-level confusion.

### Reason

A page should not try to sell, compare, explain, disclaim and close at the same time.

### Examples

- Cover: desire.
- Flights: confidence in movement.
- Hotel: desire and fit.
- Services: reassurance.
- CTA: action.

### Bad Example

A page with hero image, comparison table, legal notes, CTA and six service cards.

### Good Example

A page with one primary purpose and supporting details arranged around it.

## Rule 8: Avoid Visual Noise

### Purpose

Protect premium perception.

### Reason

Noise makes a presentation feel generated, cheap or operational.

### Examples

- Reduce borders.
- Avoid unnecessary badges.
- Avoid repeated icons.
- Avoid generic gradients.

### Bad Example

Card inside card inside card, with multiple accent colors and every value boxed.

### Good Example

Editorial sections, subtle dividers and typography-led hierarchy.

## Rule 9: No Generic AI Marketing

### Purpose

Keep language credible.

### Reason

Generic AI phrases weaken trust and make the proposal feel mass-produced.

### Examples

- Use factual positioning.
- Use supplied data.
- Avoid empty promises.

### Bad Example

"Unforgettable memories await in a luxury experience designed just for you."

### Good Example

"Prepared for two travelers, with the selected residence and journey dates clearly confirmed for review."

## Rule 10: Every Proposal Must Pass the GT63 Feeling Test

### Purpose

Ensure the artifact feels ready for a premium traveler.

### Reason

Regression tests prove function. The Feeling Test proves product quality.

### Examples

Before release, ask whether the document could be sent to a VIP traveler without explanation or apology.

### Bad Example

"It passes tests, so it is ready."

### Good Example

"It passes tests, and it feels like a premium travel brochure."

## Rule 11: Every Decision Supports the North Star

### Purpose

Keep GT63 focused.

### Reason

Design drift creates beautiful but irrelevant artifacts.

### Examples

Every layout, word, image and CTA must support the journey decision.

### Bad Example

Adding decorative sections because the page feels empty.

### Good Example

Removing an empty section so the remaining journey feels clearer.

## Rule 12: Do Not Make Client Documents Look Like Printed Software

### Purpose

Separate the premium client document from the operational interface.

### Reason

The client document is a Journey Book, not an exported dashboard.

### Examples

- Use A4 editorial pages.
- Use page breaks intentionally.
- Avoid interactive controls and UI affordances.

### Bad Example

Printing an operational interface as-is.

### Good Example

A dedicated client document with readable text, real pages, strong imagery and controlled pagination.
