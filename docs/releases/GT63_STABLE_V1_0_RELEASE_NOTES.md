# GT63 Stable v1.0

## Release Status

Release Candidate

## Product Positioning

GT63 is a premium Travel Proposal Operating System that transforms structured travel offer data into decision-ready client experiences across HTML and PDF.

Stable v1.0 is focused on one commercial promise: a travel agency can turn approved proposal data into a polished client presentation with confidence.

## Stable v1.0 Scope

Stable v1.0 includes functionality that has already been implemented and validated:

- Luxury Journey Book PDF;
- HTML proposal experience;
- separate HTML and PDF rendering paths;
- production PDF route;
- selected hotel presentation;
- flight presentation;
- Journey Investment page;
- editorial closing page;
- real image handling;
- image safety and resilience;
- deterministic regression coverage;
- production-shaped validation.

The release does not introduce new booking, payment or provider-management workflows.

## Journey Book

The accepted Journey Book structure for Stable v1.0 is:

- cinematic cover;
- journey introduction;
- hotel focus;
- flight journey;
- experience section when supported by approved data;
- Journey Investment;
- editorial closing.

Journey Book design is frozen for Stable v1.0. Future visual ideas, alternate layouts and new presentation modes belong to GT63 Next.

## Hotel Image Alias Normalization Fix

Hotel image aliases are now merged upstream before persistence. Valid `imageUrls` values are no longer lost when `images` is present as an empty array.

Supported hotel image aliases include:

- `images`;
- `imageUrls`;
- `image`;
- `imageUrl`;
- `heroImage`;
- `photo`;
- `thumbnail`;
- `gallery`.

The HTML and PDF renderers were not the root cause and required no presentation change. Regression coverage was added for alias preservation and merge/dedup behavior.

Old persisted offers with empty hotel images require re-import/regeneration.

## PDF Architecture

Stable v1.0 uses the locked Print V1 architecture:

- approved proposal data is the presentation input;
- the Journey Book uses a dedicated print-oriented renderer;
- HTML and PDF are separate presentation products;
- the PDF is not generated by screenshot export of the interactive browser page;
- Puppeteer generates A4 PDF from the dedicated Print HTML route;
- browser profiles are isolated for PDF generation;
- heavy image/PDF regression cases use isolated lifecycles for deterministic validation.

The Interactive HTML experience remains the primary interactive product artifact. The Journey Book PDF is the premium page-based document artifact.

## Known Limitations

- Stable v1.0 is a proposal and presentation platform, not a booking engine.
- Final presentation quality still depends on the quality of approved proposal data, including images, hotel descriptions, flight data and commercial conditions.
- Future design variants are deferred.
- Advanced GT63 Next concepts are out of scope for Stable v1.0.

## Deferred To GT63 Next

- new visual themes;
- additional Journey Book variants;
- major interaction redesign;
- new proposal modes;
- future automation layers;
- broader product expansion.

## Stable Maintenance Policy

Stable v1.0 accepts only release-critical fixes after lock:

- confirmed functional defects;
- security fixes;
- compatibility fixes;
- release-blocking presentation corrections.

Stable v1.0 does not accept feature creep, speculative design changes or broad refactors. New ideas move to GT63 Next.
